// =====================================================================
//  PTRe1 Adjustment Modules: Dialogue feature test
//  Paste into a Dialogue region behavior (Start with: Interact,
//  Block entry: on) or a tile's Dialogue section. Every test section
//  returns to the menu. "Finish" ends in success, "Leave" without.
//
//  Optional set-up for full coverage:
//    - a script macro named "Dialogue Test" (see the [macro] section)
//    - a GM connected, for world flags and !ask-gm
//    - Pokémon Assets active, for !cry and portraits
// =====================================================================

[start]
@Tester: Welcome to the dialogue test, {trainer}!
This box tests {b}bold{/}, {i}italic{/}, {u}underline{/}, {big}big{/} and {small}small{/} text.
---
@
A blank line or --- starts a new page, like this one.
A line break inside a page
stays on the same page.
-> menu

// ---------------------------------------------------------------- rolls

!roll athletics 10 -> roll1-pass | roll1-fail

[roll1-fail]

[rolls2]
Next: the best in the party at Perception rolls, DC 15.

[roll2-pass]
{green}Passed{/} Perception DC 15.
-> rolls3

[roll2-fail]
{red}Failed{/} Perception DC 15.
-> rolls3

[rolls3]
Last: you choose who rolls Pokémon Education, DC 12.
!roll "pokemon education" 12 choose -> roll3-pass | roll3-fail

[roll3-pass]

-> menu2

[roll3-fail]

// ---------------------------------------------------------------- money and items
[costs]
!earn 100
I gave {trainer} 100 money.
!pay 100 -> paid | broke

[paid]
...and took it back with !pay.
!pay 999999999 -> | too-much
-> items

[broke]
Couldn't take the money back. Do you own the trainer?
-> items

[too-much]
Paying 999,999,999 failed, as it should.
-> items

[items]
!give Potion 2 -> given | not-given

[given]
I gave {trainer} 2 Potions.
!take Potion 2 -> taken | not-taken

[taken]
...and took them back with !take.
-> menu2

[not-taken]
Couldn't take the Potions back.
-> menu2

[not-given]
No item called Potion in world items or compendiums, or you don't own the trainer.
-> menu2

// ---------------------------------------------------------------- memory flags
[memory]
!add test-visits 1
This is visit {flag:test-visits} to this section (party memory, stored on {trainer}).
!set actor:test-petted yes
!set world:test-world-flag -> | no-world
!if flag:test-visits:3+ -> memory-third
Come back {red}3 times{/} for a surprise.
-> memory-menu

[memory-third]
{rainbow}Third visit or more!{/} Flags remember across scenes and reloads.
-> memory-menu

[no-world]
No GM is connected, so the world flag wasn't saved.
-> memory-menu

[memory-menu]
Actor flag: "{actor:test-petted}". World flag: "{world:test-world-flag}".
> Only offered while the party flag is set [flag:test-visits] -> memory-clear
> Back -> menu2

[memory-clear]
!clear test-visits
!clear actor:test-petted
!clear world:test-world-flag
Cleared. The visit count is now "{flag:test-visits}" (empty).
-> menu2
